# Weather App 🌤️

Проект интерактивного погодного приложения, выполненный в рамках стажировки от [PREAX](https://preax.ru).

Приложение отображает текущую погоду, детализированные параметры (влажность, давление, видимость, ветер и т.д.), а также позволяет просматривать прогноз на 24 часа и на 5 дней с помощью удобного слайдера.

## Особенности проекта
* **Семантическая верстка**: Использование HTML5-тегов (`<header>`, `<main>`, `<section>`, скрытый `<h1>` для скринридеров) с заботой о доступности (a11y) и SEO.
* **Методология БЭМ**: Код написан по правилам БЭМ (Блок, Элемент, Модификатор), что делает CSS модульным и легко масштабируемым.
* **Vanilla JavaScript**: Никаких сторонних библиотек. Логика разбита на ES6-модули для удобства поддержки и инкапсуляции.
* **Векторная графика**: Иконки реализованы через SVG и CSS-маски (`-webkit-mask`), что позволяет легко управлять их цветом и сохранять идеальную резкость на любых экранах.
* **Адаптивность**: Приложение прекрасно выглядит как на мобильных телефонах, так и на больших экранах десктопов. Адаптивный слайдер подстраивает отступы под ширину экрана.
* **Отделение данных от визуала**: JavaScript отвечает только за данные, а сложные градиенты прогресс-баров и стили управляются через CSS-модификаторы.

## Технологии
* HTML5
* CSS3 (Flexbox, CSS Variables, Gradients, CSS Masks, Media Queries)
* JavaScript (ES6+, Modules)

## Структура проекта
* `index.html` — главная и единственная страница приложения.
* `styles/` — папка с CSS-файлами, разбитыми по БЭМ-блокам.
* `scripts/` — папка с модульным JavaScript-кодом (отдельные файлы для конфигурации, данных, слайдера прогноза и деталей погоды).
* `public/` — статичные ассеты (иконки погоды, логотип, фоновые изображения).

## Как запустить
Проект не требует сложной сборки (сборщиков вроде Webpack или Vite). 
Для корректной работы ES6-модулей достаточно запустить его через любой локальный веб-сервер. Например, с помощью расширения **Live Server** в VS Code.

1. Склонируйте репозиторий.
2. Откройте папку проекта в редакторе кода.
3. Запустите `index.html` через Live Server.
